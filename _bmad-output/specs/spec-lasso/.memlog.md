topic: Lasso — open-source iOS client for herdr
updated: 2026-11-03T22:34
---

- (direction) Owner: iOS client for herdr, features from Heeler and Alma, Makefile-driven like fridge.menu, BMAD spec+epics, git-dod + WAL, open source; reason: client with no backdoors.
- (decision) License MIT.
- (decision) Name Lasso (Cowboy Hero dropped: 'Cowboy for Herdr' already on App Store); bundle prefix dev.lasso.
- (decision) iOS 18+, SwiftUI, Swift 6 strict concurrency.
- (decision) Transport SSH only: libssh2+OpenSSL built from SHA-256 pinned source by make native; herdr API via direct-streamlocal channels to herdr.sock, one request per channel, long-lived channel for events.subscribe; exec-channel fallback.
- (decision) Terminal renderer libghostty via pinned prebuilt (libghostty-spm exact revision+checksum); tracked risk, build-from-source later.
- (constraint) No telemetry/analytics/crash/ads SDKs; no servers operated by us; every hard-coded host in docs/network-allowlist.txt; enforced by make audit.
- (constraint) All build/test/release via Makefile targets; logic in local Swift packages testable with swift test.
- (constraint) herdr API has no stability guarantee: decode leniently, unknown fields never crash.
- (constraint) SSH private keys in Keychain ThisDeviceOnly; host key pinned on first use, mismatch is hard stop.
- (capability) CAP-1 add/manage hosts over SSH with on-device Ed25519 key and TOFU pinned fingerprint.
- (capability) CAP-2 live agent list across workspaces sorted blocked>working>done>idle, updated via events.
- (capability) CAP-3 read agent output.
- (capability) CAP-4 send prompt and keys to an agent.
- (capability) CAP-5 live terminal attach to pane with key bar and takeover.
- (capability) CAP-6 notify when an agent becomes blocked or done (local notifications).
- (capability) CAP-7 basic management: start agent, create/rename/close workspace and tab.
- (capability) CAP-8 reconnect and resnapshot; events treated as invalidation.
- (capability) CAP-9 reproducible auditable build: make native, make audit, pinned deps documented.
- (decision) Non-goals for MVP: transcript chat view, approval buttons, pairing plugin, push relay/Live Activities, worktrees, SFTP files, iPad layout, jump host, overlay networks, any account system.
- (assumption) Hosts run OpenSSH with stream-local forwarding allowed (default).
- (question) App Store account / Apple team and GitHub org for publishing?
- (question) Push while app is killed needs own APNs relay — ever in scope, or local notifications only?
- (event) Self-validate: coherence pass OK (9 caps w/ intent+success, constraints bend design, non-goals explicit); preservation pass OK, research feature split + protocol landed in SPEC/companions.
- (decision) Stories: 14 across 5 epics (foundation SSH, agents, terminal, management+notifications, release); ids composite epic-story.
- (event) stories.yaml validity check passed: required fields, unique quoted prefix-free ids, no status.
